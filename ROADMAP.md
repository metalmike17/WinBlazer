# Roadmap

Ideas for what comes next. **These are not promises, and there are no set dates.** Priorities can change as testers
report problems.

## Testing
- [ ] Windows 11 Home and Pro
- [ ] Windows 10, version 2004 or newer
- [ ] A PC without developer tools
- [ ] The setup screens and the Windows warning for unsigned downloads
- [ ] Starting the portable version from an extracted folder

## Fixes to look at
- [ ] Offer the offline disk repair (`chkdsk /spotfix`) when a disk check asks for it
- [ ] Show the correct time zone label in repair logs
- [ ] Read disk and repair results on Windows in languages other than English
- [ ] Stop another program from being able to block WinBlazer from opening

## Found a bug?
[Send a bug report](https://github.com/metalmike17/WinBlazer/issues/new?template=bug_report.yml). Remove personal
details first.
