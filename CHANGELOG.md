# Change history

What changed in each version of WinBlazer.

## 0.1.0 beta (November 27, 2026)
The first public beta. [Download](https://github.com/metalmike17/WinBlazer/releases/tag/v0.1.0)

- Dashboard and system monitor
- Cleanup tools: temporary files, caches, browser data, disk space and built-in apps
- Game Mode, system tweaks, Startup Manager, memory and network tools
- Disk repair, drive health, Driver Manager, Shortcut Fixer and Registry Cleaner
- Backups or undo for many changes. Some actions, including cleanup, cannot be undone
- Extra protections for features that run as administrator
- Download as an installer or a portable ZIP

Known problems are listed in the [README](README.md#known-issues).
