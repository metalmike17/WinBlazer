WinBlazer (BETA) - portable version

STILL IN TESTING. Expect bugs and use it at your own risk. WinBlazer can permanently delete files and
change Windows settings. Back up important files first.

To start
1. Extract the whole ZIP to a folder you will keep. Do not run it from inside the ZIP.
2. Double-click PCOptimizer.exe (the app's earlier name). The .NET files it needs are included.
The program is not code-signed, so Windows may warn about it or block it. Do not turn off your antivirus.

Limits of the portable version
- Features that need administrator rights are not available. For those, use the installer.
  Do NOT right-click and "Run as administrator": other programs may be able to change files in this folder.
- "Portable" means no installation. It does not keep everything in this folder: settings, history and
  backups are saved in %LOCALAPPDATA%\PCOptimizerNet, the same place the installed version uses.
- If you use automatic cleaning or Game Mode, do not move, rename or delete this folder while they are on.
- No Start menu or desktop shortcut is created.

To remove
Turn off automatic cleaning and Game Mode, restore any changes you want to undo, close WinBlazer, then
delete this folder. Deleting it does not undo changes made to Windows.
